14. OBJETIVO DEL ROOM MAP

El mapa busca que cada funcionalidad tenga una ubicación clara y que el usuario pueda entender rápidamente dónde realizar cada tarea.

La navegación debe mantenerse simple, sin exceso de pantallas ni menús.
